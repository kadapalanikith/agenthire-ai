# Frontend engineering evaluation guide

## What strong evidence looks like
- **React**: building components, hooks or state management in a shipped product or substantial project.
- **JavaScript**: writing application logic, asynchronous code (promises, async/await) and debugging in the browser.
- **CSS**: building responsive layouts with flexbox or grid, design systems, or accessibility-minded styling.
- **Next.js**: routing, server rendering or static generation in a deployed application.
- **Tailwind CSS**: styling production interfaces with utility classes or maintaining a shared configuration.
- **Testing**: unit or end-to-end tests (Jest, Playwright, Cypress) written as part of the work.

## Experience
Count professional experience (full-time, part-time, contract or internships listed as roles). Personal
projects demonstrate skills but do not add to years of professional experience.

## Seniority signals
Ownership of features end to end, performance or accessibility improvements with measurable results,
mentoring, and contributions to shared tooling indicate readiness for more senior frontend roles.

## Common gaps to note
Missing required skills, experience below the stated minimum, or skills only listed without any
described use. Note gaps factually; do not speculate about reasons.
